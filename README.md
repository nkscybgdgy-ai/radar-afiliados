# Radar de Afiliados

Plataforma de inteligência para afiliados da Shopee (nicho: produtos para casa). Leia o `CLAUDE.md`.

```bash
npm install
npm run dev          # http://localhost:3000, 100% local (dados fictícios, login e pagamento simulados)
npm test             # testes de unidade/integração (PGlite em memória)
npm run job:daily    # snapshot diário local
```

Nenhum serviço pago é conectado antes do lançamento. O que conectar depois: `LANCAMENTO.md`.
